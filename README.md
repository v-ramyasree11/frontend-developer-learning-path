# Frontend Developer Learning Path

A frontend learning path webpage built with HTML5 and CSS3 to showcase essential web development topics in a clean, card-based layout.

## 🌐 Live Demo

[View Live Website](https://v-ramyasree11.github.io/frontend-developer-learning-path/)

## 📌 Project Overview

This project presents a collection of important frontend development topics, from HTML and CSS fundamentals to JavaScript and React, using a visually organized card layout.

## ✨ Features

- Clean and organized user interface
- Blue background with colorful card borders
- Flexbox-based card layout
- Custom typography using Google Fonts
- Responsive layout for mobile and desktop, if tested

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Netlify

## 📂 Project Structure

frontend-developer-learning-path/

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/v-ramyasree11/frontend-developer-learning-path.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
